# MARK GROUPS Website — Separate Files

## Structure

```text
mark-groups-website/
├── index.html
├── style.css
├── script.js
├── server.js
└── package.json
```

## Run locally

1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run:

```bash
npm start
```

4. Open:

```text
http://localhost:3000
```

No `npm install` is required because this version uses Node's built-in `http` server.

## Important

- `index.html` = page structure/content
- `style.css` = all visual styling, layout, responsive CSS and animations
- `script.js` = browser-side sliders, counters, reveals, hover/interaction logic
- `server.js` = Node.js local static server
- `package.json` = Node start command

Replace the `LOGO IMAGE HOLDER` in the footer with the final MARK logo image when ready.
