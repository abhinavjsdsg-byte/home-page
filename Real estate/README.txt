MARK GROUPS — REAL ESTATE PAGE

FILES
- index.html
- style.css
- script.js
- server.js

IMAGE HOLDERS / FILES
Place these image files in the same folder:
1. 141acre.png
2. Young india.png
3. LOGO-removebg-preview.png

LOGO
The header and footer both load LOGO-removebg-preview.png beside index.html.
The logo scales automatically for desktop, tablet, and mobile layouts.

IMPORTANT
- Featured Properties contains ONLY 2 projects: Young India Housing and Prime Land in Kokapet.
- Featured property cards have NO arrow and NO navigation link.
- The hero uses 141acre.png and has no video button.
- Final CTA uses a FULL-WIDTH BACKGROUND IMAGE, not a small image card.
- BUY / INVEST / PARTNER are display cards and do not navigate.
- Scroll reveal and number counter animations are included.
- Hover effects are included.
- Construction/interior/furniture links are placeholders because this is the Real Estate page template.

RUN WITH NODE
1. Install Node.js.
2. Open terminal in this folder.
3. Run: node server.js
4. Open: http://localhost:3000
